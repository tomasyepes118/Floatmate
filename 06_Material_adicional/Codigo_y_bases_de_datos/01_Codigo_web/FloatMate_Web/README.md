# FloatMate Web

Prototipo de gestión de vehículos y viajes del Proyecto Integrador de Aula de Tomás Yepes Arboleda. Desarrollado con HTML, CSS, Bootstrap y JavaScript.

## Ejecución

Abra index.html en el navegador. No necesita instalar dependencias ni conexión a internet. Bootstrap se incluye en assets/vendor/ con su licencia.

Acceso de demostración: usuario admin, contraseña floatmate123.

## Funciones

- Inicio de sesión de demostración.
- Panel de resumen de vehículos y viajes.
- Búsqueda, filtrado y registro de vehículos.
- Consulta y programación de viajes.

## Comprobación manual

Ingrese, recorra las pantallas, registre un vehículo y programe un viaje. Pruebe también una contraseña incorrecta y una placa repetida para revisar las validaciones.

Los datos se guardan en el navegador. El inicio de sesión se comprueba en el cliente; falta implementar una API, autenticación en servidor y conexión a PostgreSQL. Use únicamente datos de demostración.

Consulte el README de la raíz para ubicar los informes, mockups, diagramas y scripts de bases de datos.
