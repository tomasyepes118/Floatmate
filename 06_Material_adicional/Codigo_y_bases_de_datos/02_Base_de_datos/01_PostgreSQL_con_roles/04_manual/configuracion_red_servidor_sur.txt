# FLOATMATE - CONFIGURACION DE RED DEL SERVIDOR SUR
#
# Estas lineas NO son un script SQL. El administrador debe aplicarlas en los
# archivos de configuracion del PostgreSQL instalado en el equipo Sur.

1. En postgresql.conf:

listen_addresses = '*'
port = 5432
password_encryption = 'scram-sha-256'

2. En pg_hba.conf agregue la siguiente linea, reemplazando IP_NORTE por la IP
   real del servidor Norte. /32 autoriza solamente ese equipo:

host    floatmate_sur    floatmate_fdw    IP_NORTE/32    scram-sha-256

Ejemplo si Norte usa 192.168.1.10:

host    floatmate_sur    floatmate_fdw    192.168.1.10/32    scram-sha-256

3. Reinicie el servicio PostgreSQL del equipo Sur.

4. En el firewall del equipo Sur permita TCP 5432 solo desde la IP de Norte.

5. Desde Norte verifique conectividad antes de ejecutar el FDW:

psql -h IP_SERVIDOR_SUR -p 5432 -U floatmate_fdw -d floatmate_sur

# No abra el puerto 5432 a todo Internet. Esta configuracion es para una red
# privada de laboratorio. Cambie las claves de ejemplo antes de usar datos reales.
