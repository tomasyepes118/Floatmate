# Seguridad y datos de demostración

FloatMate es un proyecto académico en desarrollo. El acceso `admin` / `floatmate123` del prototipo se comprueba en JavaScript y es visible para cualquier visitante. No protege información real.

Los scripts del laboratorio con roles incluyen claves de ejemplo identificadas en su guía. Se conservan para reproducir la entrega local. No use esas claves, los usuarios de ejemplo ni los datos de demostración en un entorno real. Si esas claves ya se utilizaron fuera del laboratorio, cámbielas antes de compartir el repositorio.

No agregue archivos `.env`, claves privadas, tokens, respaldos de bases reales ni datos personales de pasajeros o conductores. Los documentos académicos pueden contener nombres de autores; revise su contenido antes de cambiar el repositorio de privado a público.

Si encuentra una credencial real expuesta, avise al propietario por un canal privado y revoque la credencial. Evite copiarla en issues o pull requests. Retirarla del último archivo no la elimina del historial de Git.

Antes de un uso empresarial se requieren autenticación y autorización en servidor, gestión externa de secretos, conexión segura a la base de datos, respaldos y pruebas funcionales y de seguridad.
